# hxyfront-62004 雪板调校工单台

源提示词编号：6

面向滑雪板调校店的装备维护前端系统。技师登记工单（品牌、长度、板型、刃角、打蜡类型、客户偏好），
在底板示意图上标记修补位置，登记刃角复核并交付；可按完工状态/板型筛选，查询客户历史维护记录。

## 状态规则

- 每张工单：**待复核 → 复核通过 → 已交付**。
- 底板损伤必须先在示意图上标记修补位置，才能登记刃角复核；底板确实无损伤时可标记唯一的「免检点」。
- 复核通过后改动**刃角或客户偏好**，原复核自动失效，工单回到待复核（按复核时的快照比对）；
  改品牌、长度、板型、打蜡、损伤标记不影响复核。
- 同一客户存在**未交付**雪板（待复核或复核通过）时，拒绝登记新工单，需先交付；已交付工单只读。
- 完工筛选（全部进行中/待复核/复核通过/完工交付）、刃角参数、损伤标记、指标与客户历史全部实时同步。

## 数据

数据只存浏览器（localStorage，键 `ski-tuning-workbench:v1`），刷新后保留；首次打开写入三张种子工单
（ORD-106/112/118）。清空浏览器站点数据即可重置。

## 架构（状态规则 / 数据操作 / 界面分离）

- `src/types.ts`：领域模型
- `src/rules.ts`：纯函数状态规则（无 React、无存储）——状态流转、复核门槛/失效、客户去重、筛选、指标
- `src/storage.ts`：localStorage 仓储与种子数据
- `src/store.tsx`：React Context，组合规则与仓储并持久化
- `src/components/`：界面组件（表单、列表、详情、刃角参数、底板标记板、复核区、筛选、客户历史、指标）
